The `Login` component renders a full-page Slovenian login screen for the MotoTrack platform.
It uses `useAuth` to authenticate the user and `react-router-dom`'s `useNavigate` to redirect on success.
A demo credentials hint is shown below the form for easy onboarding.

## Basic usage

```tsx
import { Login } from '@markec/mototrack-platform.pages.login';

<Login />
```

## Custom redirect and signup path

```tsx
import { Login } from '@markec/mototrack-platform.pages.login';

<Login
  redirectTo="/nadzorna-plosca"
  signupPath="/registracija"
/>
```

## Inside a route

```tsx
import { Routes, Route } from 'react-router-dom';
import { Login } from '@markec/mototrack-platform.pages.login';

<Routes>
  <Route path="/prijava" element={<Login redirectTo="/" signupPath="/registracija" />} />
</Routes>
```
