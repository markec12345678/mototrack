A styled range slider built for the MotoTrack dark theme. It renders a gradient-filled track, a glowing thumb, and a live value badge — all driven by CSS variables from the MotoTrack design system.

## Basic usage

```tsx
<Slider label="Twistiness" min={0} max={100} step={1} defaultValue={65} unit="%" />
```

## Controlled slider

Pass `value` and `onChange` to control the slider from parent state.

```tsx
const [distance, setDistance] = React.useState(180);

<Slider
  label="Distance"
  min={50}
  max={500}
  step={10}
  value={distance}
  unit=" km"
  onChange={(v) => setDistance(v)}
/>
```

## Route planner — multiple sliders

Combine sliders to build a full route preference panel.

```tsx
const [twistiness, setTwistiness] = React.useState(72);
const [distance, setDistance] = React.useState(180);
const [fuelReserve, setFuelReserve] = React.useState(15);

<div style={{ display: 'flex', flexDirection: 'column', gap: '28px' }}>
  <Slider
    label="Twistiness"
    min={0}
    max={100}
    step={1}
    value={twistiness}
    unit="%"
    onChange={(v) => setTwistiness(v)}
  />
  <Slider
    label="Distance"
    min={50}
    max={500}
    step={10}
    value={distance}
    unit=" km"
    onChange={(v) => setDistance(v)}
  />
  <Slider
    label="Fuel Reserve"
    min={5}
    max={50}
    step={1}
    value={fuelReserve}
    unit=" L"
    onChange={(v) => setFuelReserve(v)}
  />
</div>
```
