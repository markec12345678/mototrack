A dark, high-contrast theme built for the MotoTrack design system. It wraps your component tree with CSS custom properties, antialiased text rendering, and the Inter typeface — giving every component a consistent, premium racing aesthetic.

## Get started

Install the package and wrap your app root:

```bash
bit install @markec/mototrack-design.mototrack-theme
```

```tsx
import { MototrackTheme } from '@markec/mototrack-design.mototrack-theme';

export function App() {
  return (
    <MototrackTheme>
      <YourApp />
    </MototrackTheme>
  );
}
```

## Midnight variant (ultra-dark)

Switch to the deeper OLED-optimised palette by setting `initialTheme="dark"`:

```tsx
import { MototrackTheme } from '@markec/mototrack-design.mototrack-theme';

export function App() {
  return (
    <MototrackTheme initialTheme="dark">
      <YourApp />
    </MototrackTheme>
  );
}
```

## Access tokens in components

Use the `useTheme` hook to read any design token at runtime:

```tsx
import { useTheme } from '@markec/mototrack-design.mototrack-theme';

export function RacingCard() {
  const theme = useTheme();

  return (
    <div
      style={{
        backgroundColor: theme.colors.surface.primary,
        border: `1px solid ${theme.colors.border.default}`,
        borderRadius: theme.borders.radius.large,
        boxShadow: theme.effects.shadows.floating,
        padding: theme.spacing.xl,
        color: theme.colors.text.primary,
      }}
    >
      <span style={{ color: theme.colors.primary.default }}>P1</span>
      <span>Marc Márquez</span>
    </div>
  );
}
```

## Override tokens

Pass a partial token object via `overrides` to customise any value without forking the theme:

```tsx
import { MototrackTheme } from '@markec/mototrack-design.mototrack-theme';

export function BrandedSection() {
  return (
    <MototrackTheme
      overrides={{
        colors: {
          primary: {
            default: '#a855f7',
            hover: '#9333ea',
            active: '#7e22ce',
          },
        },
      }}
    >
      <FeatureSection />
    </MototrackTheme>
  );
}
```

## Control the theme programmatically

Use `useThemeController` to toggle or set the theme mode from any child component:

```tsx
import { useThemeController } from '@markec/mototrack-design.mototrack-theme';

export function ThemeToggle() {
  const { themeMode, toggleTheme } = useThemeController();

  return (
    <button type="button" onClick={() => toggleTheme()}>
      {themeMode === 'dark' ? 'Switch to Default' : 'Switch to Midnight'}
    </button>
  );
}
```
