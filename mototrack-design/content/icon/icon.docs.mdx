A flexible, lightweight Icon wrapper that renders any glyph — an SVG element, emoji string, or other React node — at a consistent size and color. It serves as the foundational primitive for building icon sets across all MotoTrack scopes.

## Basic usage

Render a string glyph (emoji or unicode character):

```tsx
<Icon glyph="🏍️" size="md" label="Motorcycle" />
```

## SVG glyph via children

Pass an inline SVG as a child node for full color and size control:

```tsx
function SpeedIcon() {
  return (
    <svg viewBox="0 0 24 24" fill="none">
      <circle cx="12" cy="12" r="9" stroke="currentColor" strokeWidth="1.5" />
      <path d="M12 12L8 8" stroke="currentColor" strokeWidth="2" strokeLinecap="round" />
      <circle cx="12" cy="12" r="1.5" fill="currentColor" />
    </svg>
  );
}

<Icon size="lg" color="#f97316" label="Speed gauge">
  <SpeedIcon />
</Icon>
```

## Size scale

Six sizes are available: `xs` (12 px), `sm` (16 px), `md` (20 px), `lg` (24 px), `xl` (32 px), `xxl` (48 px).

```tsx
<Icon size="xs" glyph="🏁" />
<Icon size="sm" glyph="🏁" />
<Icon size="md" glyph="🏁" />
<Icon size="lg" glyph="🏁" />
<Icon size="xl" glyph="🏁" />
<Icon size="xxl" glyph="🏁" />
```

## Color override

Pass any valid CSS color to override the inherited `currentColor`:

```tsx
<Icon size="xl" color="#22c55e" label="Success">
  <TrophyIcon />
</Icon>
```

## Clickable icon

Provide an `onClick` handler to make the icon interactive. A hover/active animation is applied automatically:

```tsx
<Icon size="lg" color="#f97316" label="Favourite" onClick={() => console.log('clicked')}>
  <HeartIcon />
</Icon>
```

## Accessibility

- When `label` is provided the icon receives `role="img"` and `aria-label` so screen readers announce it.
- When no `label` is provided the icon is hidden from the accessibility tree via `aria-hidden="true"`.
