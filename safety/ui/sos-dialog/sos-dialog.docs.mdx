A full-screen emergency dialog designed for motorcycle riders. It auto-detects the rider's country from GPS coordinates (using `useCountryFromLocation`) and displays the correct local emergency numbers. The big call button always works — it uses a native `tel:` link that functions even without internet.

## Basic usage

```tsx
import { useState } from 'react';
import { SosDialog } from '@markec/safety.ui.sos-dialog';

function App() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button onClick={() => setOpen(true)}>🆘 SOS</button>
      <SosDialog
        open={open}
        onClose={() => setOpen(false)}
      />
    </>
  );
}
```

## Offline / no GPS fallback

When GPS is unavailable, the share buttons are disabled but the `tel:` call buttons and ICE contact links remain fully functional — no internet required.

```tsx
import { SosDialog } from '@markec/safety.ui.sos-dialog';

<SosDialog
  open={open}
  onClose={() => setOpen(false)}
  emergencyNumbers={{
    police: '112',
    ambulance: '112',
    fire: '112',
    general: '112',
  }}
  iceContacts={contacts}
/>
```
